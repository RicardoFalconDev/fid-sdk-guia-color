Color

Cómo se organiza, se nombra y se aplica el color en el SDK de FID.

Resumen Guías Tokens Código

Introducción

El color del SDK tiene dos partes. Una es la identidad de FID, que es igual en todas las integraciones: los grises, los estados y la estructura de cada pantalla. La otra es un único color de marca que define cada cliente y que el SDK aplica en las acciones y en los acentos. Con esas dos partes, el mismo SDK se ve como propio en cada integración sin perder consistencia.

Anatomía del color

Los neutros llevan la mayor parte de la pantalla: texto, fondos y bordes. El color de marca aparece solo donde hay acción o un acento: el botón principal, la casilla, los íconos de los pasos y la ilustración. Los colores de estado (error, éxito, advertencia e información) son fijos y nunca toman la marca.

Pasá el mouse por cada punto de la lista para ver dónde está en la pantalla.

    Capas

    La pantalla se arma con capas que se separan por el fondo y por un borde de 1 px, sin sombras. Cada capa tiene su token.

    Cómo se implementa

    El código nunca usa un color directo: usa un token semántico, que apunta a un color crudo de una escala. Así, cuando cambia la marca, cambia todo lo que dependía de ella.

    Marca del cliente

    El SDK tiene un solo tema, claro. Lo que cambia entre integraciones es la marca: el cliente define el color principal (primary) y el color del texto de los botones (primaryText). Del color principal sale toda la escala de marca; el resto de los colores queda igual.

    MarcaprimaryprimaryTextEscala de marca (pasos 1 a 12)Texto sobre el botón

    El contraste se calcula entre primaryText y primary, igual que el aviso del panel. Es una recomendación: no impide guardar.

    Tokens

    Cada token se nombra por su rol, nunca por cómo se ve: no existe un --azul. El nombre se arma con el grupo, el rol y, si hace falta, la parte y el estado.

    Tokens de componente

    Los botones tienen tokens propios para el fondo, el borde, el texto y el hover de cada variante: primario, secundario, terciario, de peligro y deshabilitado. Están en la referencia de tokens.

    Estados de interacción

    Cada estado tiene su propio token. Ningún estado se resuelve con opacidad ni con un color suelto.

    Hover

    El fondo pasa al paso siguiente de su escala. En el botón primario, de --accent-9 a --accent-10, que es un poco más oscuro.

    Foco

    El borde pasa al color de marca y suma un aro de 3 px con un paso claro de la misma escala.

    Deshabilitado

    Usa grises fijos y no toma la marca. Como no se puede usar, queda fuera de los requisitos de contraste.

    Accesibilidad

    El color pasa el control de contraste de WCAG 2.1. El texto normal necesita 4.5:1 (nivel AA) y llega a AAA desde 7:1. El texto grande, los íconos y los bordes de los componentes necesitan 3:1. El color nunca es la única forma de transmitir información: los errores también llevan texto y un ícono.

    Contraste de los tokens

    Dónde va la marca

    El color de marca señala la acción y los acentos. Si todo tiene el color de marca, nada se destaca.

    • Botón primario, con su hover.
    • Casilla marcada; el tilde usa el color del texto de los botones.
    • Tiles de íconos: fondo suave, borde y el ícono.
    • Borde y aro de foco de los campos.
    • Spinner e ilustraciones.

    Referencia de tokens

    Todos los tokens semánticos, por grupo. Elegí una marca para ver cómo cambian los valores: los marcados como Marca se recalculan; los demás quedan fijos. Pasá el mouse por un valor para copiarlo.

    Primitivos

    Los colores crudos de los que salen los tokens: seis escalas de 12 pasos, el blanco y el negro puros y dos escalas con transparencia. No se usan directo en componentes. Tocá un color para copiar su valor.

    Uso en CSS

    Cargá los estilos del paquete en este orden y usá los tokens con var(). El contenedor del SDK lleva la clase sdk-frame.

    html
    <link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/accent-from-primary.css">
<link rel="stylesheet" href="css/illustrations.css">
<link rel="stylesheet" href="css/icons.css">

<div class="sdk-frame"> … </div>
    css
    .sdk-btn {
  background: var(--button-primary-bg);
  border-radius: var(--radius-button);
  color: var(--button-primary-text);
}
.sdk-btn:hover { background: var(--button-primary-bg-hover); }

    La escala de marca

    El cliente solo define el paso 9. accent-from-primary.css calcula los demás: los pasos 1 a 8 mezclan el color con blanco y los pasos 10 a 12, con negro.
